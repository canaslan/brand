# Visual identity

## Direction

### Nerdy

Embrace monospace fonts and code-inspired elements. Use precise grids and mathematical proportions. Make complexity beautiful through thoughtful information hierarchy.

This direction was recorded in the original brand notes as “copied from Github”; it remains a working reference to refine into original guidance.

## Resources

- [Color system](color/README.md): shared primitives, light and dark semantic themes, and usage guidance.
- [Color tokens](color/colors.tokens.json): the canonical machine-readable palette.

Typography, logos, and imagery are not yet defined here. Add each resource with its usage guidance when it is ready.
